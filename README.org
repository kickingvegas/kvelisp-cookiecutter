* kickingvegas Cookiecutter Elisp Template

Project template used by kickingvegas for Emacs Lisp projects.

VERSION: 0.0.1-rc.1

* Requirements

- [[https://cookiecutter.readthedocs.io/en/stable/][cookiecutter]] 2.7.1+

* Usage

#+begin_src shell
  cookiecutter kvelisp-cookiecutter
#+end_src
